# PhotoDiary 需求存档

> 存档时间：2026-10-07

## 用户原始需求

开发一个拍照后自动记录日记的苹果手机 App：

1. 可以拍照或者导入照片；
2. 使用多模态大模型接口（比如 DeepSeek），根据相片内容和相片信息（时间、地点等）自动生成一段描述或简短日记（可根据 prompt 微调）；
3. 一天的日记存在一个文档里，最好是 Markdown 格式；
4. 简洁、美观、易用；
5. 全部开发和测试完成后通过大象发消息通知。

## 方案补充（考虑不周之处的完善）

| 事项 | 决策 |
| --- | --- |
| 多模态模型选型（用户补充：DeepSeek V4.1 Flash 支持图片） | 已核实 [DeepSeek 官方文档](https://api-docs.deepseek.com/guides/vision)：`deepseek-flash`（DeepSeek-V4.1-Flash）支持视觉输入，走 OpenAI 兼容格式（base64 data URL）。默认预设即 DeepSeek Flash；LLM 接口抽象为 OpenAI 兼容协议，Base URL / Model / API Key / Prompt 模板全部可配置，另内置通义千问 qwen-vl-max、OpenAI gpt-4o 预设与自定义项 |
| 数据存储 | 照片存 App Documents/images/，日记按天归档为 `YYYY-MM-DD.md`（相对路径引用图片），支持 Files App 访问与系统分享导出 |
| 元数据 | 拍摄/导入时间、EXIF 时间、GPS 反地理编码为可读地点（CLGeocoder） |
| 隐私 | API Key 存 Keychain；照片与日记全部本地保存，仅用户主动点击生成时才上传图片给配置的 LLM 服务 |
| 失败兜底 | 生成失败可重试，也可手动编辑日记文本 |
| 测试 | 纯逻辑（Markdown 归档、Prompt 拼装、请求构造、存储）走单元测试；整体用 xcodebuild 在模拟器构建验证 |

## 技术栈

SwiftUI + iOS 17，无第三方依赖（URLSession / PhotosUI / CoreLocation / Keychain 均为系统框架），XcodeGen 生成工程。
