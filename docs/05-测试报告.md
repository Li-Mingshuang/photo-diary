## 6. 未覆盖项与风险声明

| 项 | 原因 | 缓解措施 |
| --- | --- | --- |
| 相机实拍链路 | 模拟器无相机 | 无相机时隐藏入口；真机人工验证 |
| 定位授权/反地理编码 | 依赖系统服务与网络 | 全链路失败静默降级，不阻断主流程 |
| 真实 LLM API 调用 | 无测试 API Key | 请求构造/响应解析已单测覆盖；设置页提供「测试连接」 |
| PhotosPicker 交互 | 系统 UI 不可自动化 | 导入解析逻辑（PHAsset/EXIF）独立成纯函数便于后续覆盖 |

## 7. 结论

迭代五后：构建通过、63 个单元测试全绿、3 个全流程 UI 自动化测试通过，达到交付标准。迭代四期间发现并修复：① 画像测试临时目录未创建导致写盘崩溃（setUp 补 createDirectory）；② 照片选择器冷启动网格加载期 AX 滚动抖动（kAXErrorCannotComplete），两处 picker 点击改为等待 2s + 坐标点击。迭代五：标签同频次排序测试期望写错（Unicode 序 火<秋），代码无误仅修正测试。迭代四期间发现并修复：① 画像测试临时目录未创建导致写盘崩溃（setUp 补 createDirectory）；② 照片选择器冷启动网格加载期 AX 滚动抖动（kAXErrorCannotComplete），两处 picker 点击改为等待 2s + 坐标点击。真机联调（相机 + 定位 + 真实 Key 生成日记 + 积累信号后手动/自动提炼画像并观察文风变化）为上线前最后一步人工验收。
