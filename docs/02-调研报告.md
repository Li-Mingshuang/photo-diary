# 02-调研报告：多模态大模型选型与关键能力核实

> 调研时间：2026-10-07

## 1. 调研目标

为「拍照自动生成日记」场景选择默认的多模态大模型接口，需满足：

1. 支持图片输入（视觉理解）；
2. API 可公开申请、按量付费、国内可用；
3. 中文写作能力好（日记正文质量直接决定产品体验）；
4. 接口协议主流，便于后续替换。

## 2. 背景：一次用户纠正

初始方案曾假设「DeepSeek 官方 API 不支持图片输入」，计划用 DeepSeek 做纯文本兜底。用户指出 **DeepSeek V4.1 Flash 已支持图片**，经官方文档核实属实，遂将其调整为默认预设。

## 3. DeepSeek 视觉能力核实（官方文档）

来源：[DeepSeek API：Vision](https://api-docs.deepseek.com/guides/vision)、[Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing)

| 项目 | 结论 |
| --- | --- |
| 模型名 | `deepseek-flash`（DeepSeek-V4.1-Flash），另有 `deepseek-v4-pro`（**不支持**视觉） |
| Base URL | `https://api.deepseek.com`（OpenAI 兼容），`https://api.deepseek.com/anthropic`（Anthropic 兼容） |
| 图片传入方式 | ① base64 data URL（内联，本项目采用）② 外部 https URL ③ Files API file_id |
| 请求格式 | OpenAI Chat Completions：`content` 数组内 `{type:"image_url", image_url:{url:"data:image/jpeg;base64,..."}}` |
| 支持格式 | JPEG / PNG / GIF / WebP（按真实内容嗅探，不看文件名） |
| 图片限制 | 单张 ≤ 32 MiB（内联）、单边 ≤ 8192 px、请求体 ≤ 48 MiB |
| 图片计费 | 推理前自动缩放到约 1300×1300 总像素，单图上限 1024 tokens |
| 上下文 / 输出 | 1M context，最大输出 384K |
| 价格（deepseek-flash） | 缓存未命中输入 $0.3/1M tokens（peak），输出 $1.2/1M tokens（peak）；off-peak 半价 |
| 注意事项 | 图片只允许放在 `user` 消息里（system/assistant 含图会 400） |

**成本估算**：一次日记生成 ≈ 1 张图（≤1024 tokens）+ prompt（约 300 tokens）+ 输出（约 300 tokens）≈ ¥0.01 量级/次，可忽略。

## 4. 备选方案对比

| 服务 | 视觉 | 协议 | 备注 |
| --- | --- | --- | --- |
| **DeepSeek V4.1 Flash**（默认） | ✓ | OpenAI 兼容 | 便宜、中文好、国内直连 |
| 通义千问 Qwen-VL Max | ✓ | OpenAI 兼容模式（DashScope） | 视觉理解能力强，作备选 |
| OpenAI GPT-4o | ✓ | OpenAI 原生 | 质量高，需海外网络 |
| 自定义 OpenAI 兼容 | 可开关 | OpenAI 兼容 | 任意第三方/自建网关 |

**架构决策**：不绑定任何一家 SDK，抽象为「OpenAI 兼容 Chat Completions 客户端 + 可配置预设」，预设间切换零代码改动。DeepSeek 特有的 thinking 参数不下发，保持负载通用。

## 5. 其他技术点结论

| 问题 | 结论 |
| --- | --- |
| 相册照片时间/地点 | 优先 `PhotosPickerItem.itemIdentifier → PHAsset`（creationDate/location 最准），兜底 ImageIO 解析 EXIF（`DateTimeOriginal` + GPS 字典） |
| 拍照时地点 | `CLLocationManager.requestLocation()` 单次定位 + `CLGeocoder` 反地理编码（locality · subLocality · areasOfInterest），8s 超时、失败静默降级为「位置未知」 |
| 日记存储 | 纯 Markdown 文本文件按天归档，不引入数据库；图片落盘、md 相对路径引用，天然支持导出与文件 App 访问 |
| API Key 存储 | Keychain（GenericPassword），按预设 id 分别存 JSON 字典 |
