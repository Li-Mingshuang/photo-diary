## 2.1 UI 自动化测试期间发现的真实产品 bug

**PhotosPicker 放在 `Menu` 里无法弹出**（SwiftUI 已知问题）：UI 测试驱动「+ → 从相册导入」时菜单正常展开、菜单项可点击，但系统照片选择器始终不呈现——真机上用户同样会遇到。修复：Menu 里改为普通 `Button` 置位 `showingPhotosPicker`，再用 `.photosPicker(isPresented:)` modifier 呈现。修复后全流程 UI 测试通过。这是本轮 UI 自动化测试最大的价值产出。

UI 测试踩坑记录：

| 问题 | 解法 |
| --- | --- |
| 工具栏 `Menu` 按钮 tap 报 `kAXErrorCannotComplete`（AX 滚动失败） | 改用 `coordinate(withNormalizedOffset:).tap()` 坐标点击 |
| 菜单项类型排查 | 打印 `app.debugDescription` 无障碍树确认元素类型/label |
| 截图回传 Mac | 模拟器与 Mac 共享文件系统，测试内直接 `FileManager` 写 `/tmp` 绝对路径 |

## 3. 关键实现决策

1. **XcodeGen 而非手写 pbxproj**：环境无 xcodegen 时先 `brew install xcodegen`，工程配置全部收敛到 `project.yml` 一个文件，可重复生成。
2. **每预设独立存 Key**：Keychain 单条目存 `[presetID: key]` 的 JSON，切换服务不清空已填 Key。
3. **占位符替换顺序**：先 `{datetime}` 后 `{date}`，避免子串误匹配（单测覆盖）。
4. **时间精度取舍**：md 标题只存到分钟，解析重建时秒归零；单元测试按分钟断言，避免往返精度误报。
5. **模拟器兼容**：无相机时隐藏「拍照」入口，保留「从相册导入」，保证模拟器可完整走通主流程。
