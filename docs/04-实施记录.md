## 3. 关键实现决策

1. **XcodeGen 而非手写 pbxproj**：环境无 xcodegen 时先 `brew install xcodegen`，工程配置全部收敛到 `project.yml` 一个文件，可重复生成。
2. **每预设独立存 Key**：Keychain 单条目存 `[presetID: key]` 的 JSON，切换服务不清空已填 Key。
3. **占位符替换顺序**：先 `{datetime}` 后 `{date}`，避免子串误匹配（单测覆盖）。
4. **时间精度取舍**：md 标题只存到分钟，解析重建时秒归零；单元测试按分钟断言，避免往返精度误报。
5. **模拟器兼容**：无相机时隐藏「拍照」入口，保留「从相册导入」，保证模拟器可完整走通主流程。
